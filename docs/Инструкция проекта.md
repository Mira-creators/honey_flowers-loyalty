Проект: «Медовая карта» для цветочного магазина Honey Flowers (Ташкент) — программа лояльности в Telegram (бот + Mini App) и склад внутри неё. Три роли: владелица, флорист, покупатель. Стек: Cloudflare Workers + D1, Hono, grammY, TypeScript, монорепозиторий (packages/core, service, stock, contracts; apps/worker, apps/miniapp; qa/). Срок — передать готовый продукт до 31.12.2026.

Правила для всех чатов:
1. Перед работой прочитай в подключённой папке docs/План до запуска.md — там твоя роль, ветка, папка, свои файлы, номера миграций и график. Затем docs/Honey Flowers — контекст проекта.md и docs/Спорные вопросы.md.
2. Пиши только в свою папку на ноутбуке и только свои файлы. Общие файлы — только добавлением, с отметкой в отчёте.
3. Перед записью сверяй файлы на ноутбуке с тем, от чего начинал; изменился файл — сначала разберись. Окончания строк CRLF.
4. Пушить можно свою ветку и dev — только законченную работу: сначала git pull origin dev, затем тесты, typecheck и сборка, затем push. Без --force. В main не пушь никогда — это делает только Мираслав. Нет доступа к терминалу ноутбука — дай готовые команды.
5. Токены и секреты не пиши в чат и в файлы.
6. Каждая задача заканчивается проверкой: npm test, typecheck, сборка, e2e если затронуты экраны. Каждая исправленная ошибка — с тестом.
7. Нагрузочные тесты — только локально; полигон бережём (общий дневной лимит базы Cloudflare).
8. Решения о правилах, деньгах и данных клиентов не принимай молча: опиши варианты для Мираслава.
9. В конце работы — отчёт для Штаба: сделано, затронутые общие файлы, миграции, что проверено, что не сделано.
10. Общаемся по-русски, коротко и по делу.
