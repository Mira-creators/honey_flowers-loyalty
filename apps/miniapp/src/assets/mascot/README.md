# Маскот «Медовой карты» — шмель

Сейчас в приложении временный векторный шмель (`src/ui/mascot.ts`) — заглушка до иллюстраций **Мираславы**.

## Как заменить на настоящие рисунки

1. Положите файлы **в эту папку** (`apps/miniapp/src/assets/mascot/`) с такими именами:

   | Файл | Поза | Где показывается |
   | --- | --- | --- |
   | `flying.svg` / `.png` / `.webp` | шмель **летит** | пчёлка над сотами (анимация полёта), экран регистрации |
   | `sitting.svg` / `.png` / `.webp` | шмель **сидит** | значок уровня, спокойные экраны |
   | `celebrating.svg` / `.png` / `.webp` | шмель **радуется подарку** | открытие подарка, новый уровень, заполненная карта |

2. Формат: квадратный холст, **прозрачный фон**, шмель по центру, PNG/WebP примерно 512×512 (до ~60 КБ) или SVG.
3. Пересоберите приложение: `npm run build` (или выложите — сборка сделает это сама).

Код менять не нужно. Если какой-то позы нет — берётся `flying`, а если файлов нет совсем — временный векторный шмель.
