# Дизайн-система «Медовая карта» (B1, версия 1 — 27.11.2026)

Одна система на всё приложение: клиент, касса, владелица, склад, кабинет. Живая витрина —
**тестовая панель → «Дизайн» → «Витрина компонентов»** (светлая и тёмная тема переключаются там же).

## Направление

«Акварельный гербарий» по логотипу: белая тёплая бумага, тонкие травяные линии вместо теней,
акварельный клевер и шмели. Цвет несёт смысл:

| Цвет | Роль | Где |
| --- | --- | --- |
| Янтарь HONEY (`accent`) | мёд и **одно главное действие на экране** | баланс, «Начислить», «Продать» |
| Зелень клевера (`leaf`, `good`) | успех, «всё в порядке», подсказки | тост «готово», плашка-подсказка |
| Розовый клевер (`petal`) | подарки, праздники | соты с подарком, день рождения |
| Красный (`bad`) | ошибка, опасное действие | «Удалить», «не хватает» |
| Тёмный янтарь (`warn`) | предупреждение | «сгорит», «уходит в минус» |

Заголовки, суммы мёда и денег — **Cormorant Garamond** (`--font-display`), как надпись HONEY. Остальной текст — системный шрифт.

## Три источника — больше ничего

1. **Цвета** — только `var(--c-<роль>)`, роли в `config/themes.ts` (`COLOR_ROLES`). Никаких `#hex` и `rgba()` в экранах.
2. **Размеры** — только токены из `ui/tokens.css`:
   - отступы `--sp-0…--sp-12` (шаг 4 px; есть промежуточные `--sp-1h` 6, `--sp-2h` 10, `--sp-3h` 14);
   - шрифт `--fs-2xs` 11 · `xs` 12 · `sm` 13 · `md` 15 · `lg` 17 · `xl` 20 · `2xl` 24 · `3xl` 31, `--fs-input` 16 (меньше — iPhone увеличивает экран при вводе);
   - скругления `--r-card`, `--r-btn` (из темы), `--r-xs` 8 · `sm` 12 · `md` 14 · `pill` · `sheet`;
   - касание `--tap` 44 (минимум для любой кнопки), `--tap-lg` 52 (главная кнопка кассы), `--tap-sm` 36 (только вторичное в плотных списках);
   - тени `--sh-1…3`, анимации `--dur-1…3`, `--ease`, слои `--z-*`.
   
   Свои числа допустимы только для геометрии рисунка (ширина иконки, высота графика).
3. **Разметка** — функции `ui/kit.ts`. Классы руками не пишем.

## Компоненты (`ui/kit.ts`)

| Функция | Что это | Пример |
| --- | --- | --- |
| `btn(text, { act, variant, size, full, iconHtml, label, busy })` | кнопка | `btn('Продать', { act: 'stSell', variant: 'primary', size: 'lg', full: true })` |
| `busy(key, el, fn)` | **защита от двойного нажатия**: пока `fn` идёт, повторные нажатия игнорируются, кнопка с кружком | `actions.stSell = el => busy('sell', el, () => api.sell(...))` |
| `field({ id, label, hint, error, suffix, inputmode })`, `setFieldError(id, text)` | поле с подписью, подсказкой и ошибкой | `field({ id: 'qty', label: 'Стеблей', inputmode: 'numeric', suffix: 'шт' })` |
| `card(html, { tone, titleHtml, asideHtml, over })` | карточка: `plain`, `soft`, `honey`, `raised` | |
| `note(html, kind)` | плашка: `info`, `good`, `warn`, `bad`, `gift` | `note('Роз осталось <b>3</b>', 'warn')` |
| `tag(text, tone)` | бейдж | `tag('Списано', 'bad')` |
| `kv(key, valueHtml, tone)` | строка «ключ — значение» (итог чека, предпросмотр) | |
| `pageHead(title, { sub, asideHtml })`, `sheetHead(title, { sub })`, `sprig()` | заголовок экрана, шапка листа с крестиком, разделитель-веточка | |
| `loadingState(text)`, `skeleton(parts)` | загрузка: шмель или серые полосы на месте списка | `skeleton(['h','row','row'])` |
| `emptyState({ title, text, action })` | пусто: что здесь будет и что сделать | |
| `errorState({ title, text, action, code })` | ошибка: по-человечески + «Повторить» | |
| `toast(text, 'ok' \| 'error' \| 'info')` (`ui/dom.ts`) | короткое сообщение, встаёт над вкладками, новое заменяет старое | |
| `sheet(html)` (`ui/dom.ts`) | нижний лист; `sheetHead` даёт крестик (действие `closeSheet`) | |

Баннер «Нет интернета» показывается сам (`ui/install.ts`), экранам ничего делать не нужно.

## Правила экранов

- У каждого экрана с данными есть три состояния: **загрузка** (`skeleton` или `loadingState`), **пусто** (`emptyState`), **ошибка** (`errorState` с «Повторить»).
- На экране **одна** главная кнопка (`primary`, янтарь). Остальные — `secondary`, `soft` или `ghost`.
- Любое действие, которое пишет в базу, — через `busy()`.
- Опасное действие — `danger-outline`; подтверждение — в листе, не в `confirm()`.
- Деньги и мёд — `font-variant-numeric: tabular-nums` (уже в `.amt`, `.kv b`, `.bal .n`).
- Тексты для клиента — в `config/texts.ts` (ru и uz), не в разметке.

## Для чата «Склад»

Старые классы (`.b`, `.acc`, `.pri`, `.full`, `.big`, `.sm`, `.it`, `.chip`, `.note-box`, `.empty`) работают как раньше —
экраны склада ничего не потеряли. Переход на систему:
1. `stock.css`: заменить числа на токены (`12px` → `var(--sp-3)`, `font-size: 13px` → `var(--fs-sm)`, `rgba(0,0,0,.25)` в тени → `var(--sh-2)`).
2. Новые и переделанные экраны собирать из `ui/kit.ts`; продажу и списание — через `busy()`.
3. Не хватает компонента — напишите в отчёт Штабу, добавлю в систему, чтобы он был один на всё приложение.
